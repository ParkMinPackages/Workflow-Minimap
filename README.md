# ParkMinPackages.Workflow.Minimap

A reusable minimap workflow package for Unity projects built on `ParkMinPackages.Workflow.Default`.

## Requirements

- Unity 6000.5 or newer
- ParkMinPackages.Workflow.Default 9.1.4 or newer

## Installation

Add the following Git URL through Unity Package Manager:

```text
https://github.com/ParkMinPackages/Workflow-Minimap.git
```

## Status

This package currently provides the initial package structure and assembly definitions. Runtime implementation will be added separately.
